# Prüfbericht 24.10.2026 – Standard hell, Hinweis auf den Dunkelmodus

## Umfang

- Standarddesign ist Hell. Die Betriebssystem-Einstellung wird nur noch befolgt, wenn «System» ausdrücklich gewählt wurde (Knopf im Kopf oder Einstellungen). Reihenfolge des Knopfs: Hell → Dunkel → System. Das Inline-Skript vor dem ersten Paint setzt `data-theme="light"`, sofern keine gespeicherte Wahl («dark» oder «system») vorliegt; `<html>` trägt `data-theme="light"` auch ohne JavaScript. Die Farbe des Browser-Rahmens (`theme-color`) folgt dem tatsächlichen Design.
- Hinweis auf den Dunkelmodus (`components/theme/ThemeHint.tsx`): erscheint nach 3 Minuten auf der Website (Zähler läuft über Seitenwechsel innerhalb der App weiter), nur wenn das Design nicht selbst gewählt wurde, die Seite hell ist, der Tab sichtbar ist und die Einwilligungsfrage beantwortet wurde (sonst alle 15 s erneut geprüft). Kleine Karte oben rechts mit Pfeil auf den Theme-Knopf (Position aus dem Knopf gemessen, folgt bei Grössenänderung), Knöpfe «Dunkelmodus ausprobieren» und «Nein danke», Schliessen-Knopf, Escape. `role="status"`, kein Fokusraub.
- Effekte auf dem Theme-Knopf: pulsierender Ring (3 ×, Petrol), solange der Hinweis offen ist; kurze Bestätigung (Skalieren mit leichter Drehung, 0.9 s) nach einem Wechsel, auch wenn direkt über den Knopf gewechselt wird. Bei «Bewegung reduzieren» keine Animation, stattdessen statischer Rahmen.
- Speicherung: Merker `nwa.themeHint` nur mit Einwilligung «Funktional» (sonst nur für die Sitzung im Speicher); auf `/cookies` (DE/EN) eingetragen, `legalVersion` auf `2026-10-24`. Texte in Deutsch, Englisch, Französisch, Italienisch.

## Prüfungen

- `npm test` (20 Tests), `npm run lint`, `npm run typecheck`, `npm run build` grün.
- Chromium mit verstellter Uhr (`page.clock`), Startseite:
  - 1366 px, System dunkel, Einwilligung «alles»: Seite startet hell (`data-theme="light"`, Hintergrund weiss, `theme-color` hell). Nach 170 s kein Hinweis, nach 185 s Hinweis sichtbar, Knopf pulsiert, Pfeil zeigt auf den Knopf (Mitte 224 px vom rechten Rand, Pfeil 205 px vom Kartenrand). «Dunkelmodus ausprobieren»: Design dunkel, Bestätigungseffekt aktiv, Hinweis geschlossen, `nwa.theme = dark`, `nwa.themeHint = 1`, `theme-color` dunkel; Effekt nach 1.5 s abgeklungen. Reload und weitere 200 s: dunkel bleibt, kein Hinweis.
  - 390 px, hell, nur notwendige Speicherung: Hinweis erscheint (Pfeil 58 px), «Nein danke» schliesst, Puls endet, kein Merker gespeichert (erwartet ohne Einwilligung).
  - 1366 px, Wechsel direkt über den Kopf-Knopf während der Hinweis offen ist: dunkel, Bestätigungseffekt, Hinweis weg, Merker gesetzt.
  - Keine Konsolenfehler in allen Durchläufen.

## Grenzen

- Der Zähler startet bei jedem vollständigen Neuladen neu («ca. 3 Minuten»); ohne Einwilligung «Funktional» kann der Hinweis nach einem Neuladen erneut erscheinen, so wie auch die Designwahl ohne Einwilligung nicht gespeichert wird.
- Nicht auf echten Geräten geprüft (Safari/iOS, Firefox, Android).
